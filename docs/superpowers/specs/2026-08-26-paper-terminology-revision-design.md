# 论文术语与学术表达修订设计

## 目标

在不改变论文实验事实、数据、公式、表格和参考文献的前提下，提升《面向真实微服务项目的证据约束混沌测试方法》的学术表达质量。

## 修订范围

- 统一混沌测试、故障注入、证据约束知识库、业务调用路径、适用性门控、稳定缺陷族等核心术语。
- 统一 ChaosAtlas、TestNode、ChaosEater、OpenTelemetry、Sock Shop 等专有名词和缩写的写法。
- 优化中文摘要、引言、相关工作、方法、实验分析和结论中的病句、口语化表达及衔接。
- 校正英文摘要和关键词中的术语对应、复合名词和学术措辞。
- 保留原章节层级、编号、公式、表格、图题、引文编号及参考文献。

## 交付与质量门槛

输出独立的修订版 DOCX，不覆盖原稿。完成后进行段落/表格结构检查，并通过 `render_docx.py` 渲染所有页面，逐页检查分页、表格、公式、字体和字符显示。
