# P4：闭环验证报告（知识库学习让方法变好了吗）

> 日期：2026-08-09
> 目标：量化"知识库随实验学习迭代"是否让候选选择变好——闭环设计的最终验证（knowledge_closed_loop.md P4）。

## 一、验证设计（非循环原则）

- **决策引擎**（decision_engine，纯知识库、无 LLM）的知识来自 P0 回流的 20 候选实验 + 判定/选择经验 + 契约清单 + 防御模式。
- **r1 前瞻池（6 候选）**：决策引擎当时不知道结局 → 预测 → 之后我们执行全部 6 个 → 结局已知。这是**真正的非循环验证**。
- **r2 前瞻池（18 候选）**：决策引擎预测完成（本报告），候选**尚未执行**——验证待后续实验。

## 五、诚实结论

1. **闭环的前半（学习 → 变好）在 r1 池上有实证**：知识库驱动的决策引擎（无 LLM）4/4 命中、2/2 正确跳过，优于 M1 盲选和随机——而且完全可审计（每条理由指向具体知识条目 + 契约 + 模式）。
2. **样本诚实**：r1 是 6 候选单池，4/4 vs 3/4 差 1 个，**统计功效仍不足**（B1 教训）。r2 执行后才能加大样本。
3. **r2 是待验证承诺**：18 候选预测已落盘，执行 top-8（约 24 次注入）后闭环才算完整闭环——这是后续实验，成本由用户定。
4. **"学习让方法变好"不等于"优于其它方法"**：P4 度量的是知识库自身的增益（4/4 vs 无知识基线），不是对外优越性声明（那仍需外部真值）。
